# Day 01 - Personal Website & Bio

In this assignment, I created and deployed a personal website using GitHub Pages and Jekyll. 

## What I Did
1. Set up a public GitHub Pages repository (`EladBio.github.io`).
2. Implemented clean architecture by separating content from styling:
   - **Content:** Managed via `_data/bio.yml` with my academic background, research interests, and contact links.
   - **Design & Layout:** Styled in `_layouts/default.html` using a modern dark-mode aesthetic with card layouts and custom CSS.
   - **Rendering:** Connected via `index.html` layout declaration.
3. Successfully published the site at [https://EladBio.github.io](https://EladBio.github.io).
